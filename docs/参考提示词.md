本项目的动态路由由后端返回，组件通过 loadView 动态加载，loadView 已自动按路由配置为组件设置 name，因此 src/views/ 下所有被动态路由加载的组件内部禁止再手动写 defineOptions({ name: 'xxx' })，否则手动命名与 loadView 生成的 name 不一致会导致 keep-alive 页面缓存失效，且多处手动命名容易冲突和双源维护不一致。请先全局排查 src/views/ 及其他被 loadView 加载的目录中所有 defineOptions 用法，逐一判断是否属于动态路由组件（静态路由、布局组件、独立弹窗组件不受此约束，不要误改），对确认属于动态路由的组件删除多余的 name 字段（若 defineOptions 中还有 inheritAttrs 等其他合法选项则只删 name 保留其余），删除后重新全局搜索自检确认无遗漏、缓存 name 来源仅剩 loadView 一处，最后将这条规范（含规则描述、原因、正误代码对比示例、适用边界）润色后合并写入项目根目录的 AGENTS.md，措辞与现有文档风格保持一致，执行修改前先列出所有将被改动的文件及理由。
